# From Waste Campus to a Sustainable Campus — EVS Project Website

A hand-built, multi-page static website for the Environmental Studies (EVS) project "From Waste Campus to a Sustainable Campus", submitted by students of Hyderabad Institute of Technology and Management.

## Run locally
No server, build step, or install is required. Open index.html in a modern browser.

## Pages
- index.html — Home, campus hotspot map, objectives, EVS units, team
- project.html — Project track, before/after comparison, problem statement, context
- objectives.html — Five objectives, interactive segregation lab, reuse examples
- evs-analysis.html — Unit I–V analysis
- risk.html — Risks, controls, simplified EIA/EMP and monitoring plan
- conclusion.html — Conclusion, team and thank you

## Structure
- assets/css/style.css — responsive design system
- assets/js/main.js — navigation and interactive modules
- assets/img/ — original illustrations and campus imagery

The website is static and can be hosted directly on Vercel.
